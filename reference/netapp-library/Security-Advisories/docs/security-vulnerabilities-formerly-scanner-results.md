# Where did Security vulnerabilities (formerly scanner results) move to?
Source: https://kb.netapp.com/Advice_and_Troubleshooting/Miscellaneous/Security_vulnerabilities_(formerly_scanner_results)
Fetched: 2026-07-07

## Applies to

- Bulletins > Security Vulnerabilities (formerly scanner results) (https://security.netapp.com/bulletins/ntap-sb-20211028-0001/)
- Scanner Reports

## Answer

Security vulnerabilities (formerly scanner results) has been retired. https://security.netapp.com/bulletins/ntap-sb-20211028-0001/

Posted by NetApp PSIRT / Published Date: 10/28/2021 / Bulletin ID: NTAP-SB-20211028-0001

### Current Advisory and Notice Documents

- Security advisories for announced vulnerabilities can be located here: https://security.netapp.com/advisory/
- The Support (http://support.netapp.com/) and Security Advisory (https://security.netapp.com/advisory/) sites should become the first stop when searching for CVEs impacting NetApp products.

### Legacy security vulnerabilities

- NetApp has stopped maintaining the static tables that previously existed on the Scanner Results page.
- The Bulletin > Security Vulnerabilities (formerly scanner results) (https://security.netapp.com/bulletins/ntap-sb-20211028-0001/) provides tables that can help you understand legacy security vulnerabilities related to NetApp products that third-party security scanners might report.
- Recognizing that users are still interested in information related to potential security vulnerabilities, Common Vulnerability Exposure (CVE) identifiers are searchable in NetApp's Bug Tools, Knowledgebase, and Support (http://mysupport.netapp.com/) sites.

## Additional Information

NetApp takes the security of our products very seriously and is committed to resolving vulnerabilities to meet the needs of our users and the broader technology community.

- As a result of a continually changing threat landscape, NetApp updated its Product Security Vulnerability Handling and Response Policy (https://security.netapp.com/policy/).
