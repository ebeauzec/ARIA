# Business continuity technical reports
Source: https://docs.netapp.com/us-en/ontap-technical-reports/business-continuity.html
Fetched: 2026-07-07

NetApp offers a wide range of solutions that rationalize where applications and data live to improve performance cost effectively. Data protection, replication, and continuous availability: ONTAP data management can simplify data protection with set-it-and-forget-it policy management, while delivering business continuity with MetroCluster and SnapMirror active sync.

Note: These technical reports expand on the [ONTAP SnapMirror active sync](https://docs.netapp.com/us-en/ontap/smbc/index.html) and [ONTAP MetroCluster](https://docs.netapp.com/us-en/ontap-metrocluster/index.html) product documentation.

## SnapMirror active sync (formerly SM-BC)

**TR-4878: SnapMirror active sync** — https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html
SnapMirror active sync is a continuously available storage solution with application-level granularity, available for ONTAP running on AFF or All SAN Array (ASA) storage systems, to meet the RPO 0 and RTO 0 needs of the most critical business applications.

## MetroCluster

**TR-4705: NetApp MetroCluster solution architecture and design** — https://www.netapp.com/pdf.html?item=/media/13480-tr4705.pdf
Describes high-level architecture and design concepts for MetroCluster features in ONTAP.

### MetroCluster IP

**TR-4689: NetApp MetroCluster IP** — https://www.netapp.com/pdf.html?item=/media/13481-tr4689pdf.pdf
MetroCluster is a continuously available storage solution for ONTAP running on FAS and AFF systems. MetroCluster IP is the latest evolution, using an Ethernet-based back-end storage fabric, providing a highly redundant configuration for the most critical business applications. Included in ONTAP; provides NAS and SAN connectivity for clients/servers using ONTAP storage.

### MetroCluster FC

**TR-4375: NetApp MetroCluster FC** — https://www.netapp.com/pdf.html?item=/media/13482-tr4375.pdf
MetroCluster provides continuous data availability across geographically separated data centers for mission-critical applications. Covers MetroCluster FC recommended practices, design decisions, and supported configurations.
