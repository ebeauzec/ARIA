# Inter-Switch Link requirements for MetroCluster IP configurations
Source: https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/overview-isl-requirements.html
Fetched: 2026-07-07

You should verify that your MetroCluster IP configuration and network meets all Inter-Switch Link (ISL) requirements. Although certain requirements might not apply to your configuration, you should still be aware of all of the ISL requirements to gain a better understanding of the overall configuration.

| Title | Description |
|---|---|
| [NetApp-validated and MetroCluster-compliant switches](https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/mcc-compliant-netapp-validated-switches.html) | Describes the switch requirements. Applies to all switches used in MetroCluster configurations, including backend switches. |
| [Considerations for ISLs](https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept-requirements-isls.html) | Describes the ISL requirements. Applies to all MetroCluster configurations, regardless of network topology and whether you use NetApp-validated switches or MetroCluster-compliant switches. |
| [Considerations when deploying MetroCluster in a shared layer 2 or layer 3 networks](https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept-considerations-layer-2-layer-3.html) | Describes the requirements for shared layer 2 or layer 3 networks. Applies to all configurations except for MetroCluster configurations using NetApp-validated switches and using direct connected ISLs. |
| [Considerations when using MetroCluster Compliant switches](https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept-requirement-and-limitations-mcc-compliant-switches.html) | Describes the requirements for MetroCluster-compliant switches. Applies to all MetroCluster configurations that are not using NetApp-validated switches. |
| [Examples of MetroCluster network topologies](https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept-example-network-topologies.html) | Provides examples of different MetroCluster network topologies. Applies to all MetroCluster configurations. |
