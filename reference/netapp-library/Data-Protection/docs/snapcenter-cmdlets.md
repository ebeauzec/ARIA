# SnapCenter 6.2 cmdlets
Source: https://docs.netapp.com/us-en/snapcenter-cmdlets/

SnapCenter provides PowerShell cmdlets to support application consistent data protection for applications, databases, host file systems, and VMs running on ONTAP systems anywhere in the hybrid cloud. The SnapCenter cmdlet reference compiles all PowerShell help pages for available SnapCenter PowerShell cmdlets.
