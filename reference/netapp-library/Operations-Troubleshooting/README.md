- **New — Value Insights (20 August 2026)**: a new feature that consolidates overall health, savings, stability, and security information for ONTAP systems into a continuous, data-driven view — useful for a single-pane rollup during a health-check or QBR engagement. **ONTAP systems only** (not yet available for E-Series/StorageGRID/CVO per the doc's own scope note).
- **New — Config Drift deprecation notice (12 August 2026)**: the Config Drift feature "will be deprecated in Digital Advisor in September 2026." No replacement workflow named; direct questions to `[e-mail address omitted]`. If a customer engagement uses Config Drift golden templates or scheduled drift reports (across customer/site/group/watchlist/cluster/host), flag the September 2026 cutover now rather than at removal.
- **Wellness Review — deprecation now finalized (15 July 2026 entry)**: the previously-flagged "starting July 2026" removal is now confirmed complete — per the 15 July 2026 entry, "The Wellness Review feature has been deprecated and is no longer available in Digital Advisor as of July 2026." If a customer engagement still references the Wellness Review workflow (subscription emails, on-demand reports), they have lost access — direct questions to `[e-mail address omitted]` per NetApp's own guidance, no replacement workflow named in the doc.
- **New Security Report (04 Feb 2026)** — Digital Advisor now provides a unified ONTAP security-risk view (misconfigurations, compliance gaps, security issues) across clusters, SVMs, and volumes — useful as a first-pass discovery tool alongside [Security-Hardening](../Security-Hardening/README.md).
- **Upgrade Advisor: mixed-patch-level support (04 Feb 2026)** — Upgrade Advisor now generates upgrade reports for clusters with nodes on different patch levels within the *same* ONTAP major release (still requires a single major version across the cluster).
- **Upgrade Advisor: end-of-limited-support version planning (04 Feb 2026)** — Upgrade Advisor now supports generating upgrade plans for ONTAP versions that have already reached end of limited support, with a 9-month grace period.
- **Widget renames (03 June 2026)** — Tech Refresh → System Refresh; Capacity Additions → Storage Expansion; Renewals → Support Renewals. Functionality unchanged — flag this if a customer-facing runbook or screenshot still references the old names.
- **Health Check GraphQL migration and AutoSupport data-dependency change (29 June 2026)** — Health Check migrated from the Public API to GraphQL; Recommended Software shelf/drive counts and min/latest version recommendations are now calculated more accurately (cluster-level, effective cluster version). **Operationally relevant**: systems that haven't sent an AutoSupport since October 2025 will show *no data* in Health Check/Recommended Software views, and systems without an AutoSupport in the last 30 days will show *outdated* values — if a customer's Health Check view looks empty or stale, check AutoSupport delivery (see below) before assuming a Digital Advisor bug.

- [Support and Diagnostics menu (Unified Manager)](https://docs.netapp.com/us-en/active-iq-unified-manager/config/reference_support_and_diagnostics_menu.html)
- [How to verify support.netapp.com is receiving AutoSupports via Active IQ (KB)](https://kb.netapp.com/on-prem/ontap/Ontap_OS/OS-KBs/How_to_Verify_support.NetApp.com_is_receiving_my_Autosupports_using_Active_IQ)
- Mechanism: AutoSupport is the telemetry channel (config, status, performance, and event data) that feeds both NetApp Support case diagnosis and Active IQ Digital Advisor's proactive risk/upgrade recommendations.
- Common connectivity failure: outbound HTTPS (443) to `support.netapp.com` blocked by firewall/proxy — this is the single most common reason AutoSupport delivery silently fails; whitelist explicitly rather than assuming default-allow.

- [ONTAP 9 Performance — Resolution Guide (KB, starting point for any perf issue)](https://kb.netapp.com/on-prem/ontap/Perf/Perf-KBs/ONTAP_9_Performance_Resolution_Guide)
- [ONTAP Performance KB index](https://kb.netapp.com/on-prem/ontap/Perf/Perf-KBs)

- [ONTAP Disk utilization and latency — resolution guide](https://kb.netapp.com/Advice_and_Troubleshooting/Data_Storage_Software/ONTAP_OS/ONTAP_Disk_utilization_and_latency_-_Resolution_Guide)
- [Identify performance issues in Active IQ Unified Manager](https://docs.netapp.com/us-en/ontap/performance-admin/identify-performance-issues-unified-manager-task.html)
- Triage order (per the Resolution Guide): confirm whether latency is client-perceived (network/host path) vs. cluster-perceived (`qos statistics volume latency show`, disk/aggregate utilization) before assuming a storage-side root cause — a large share of "ONTAP is slow" tickets resolve to host multipathing/queue-depth or network-path misconfiguration, not the array. Cross-check against [Host-Integration-Cabling](../Host-Integration-Cabling/README.md) and [Networking-Performance](../Networking-Performance/README.md) for the host/network side of that triage.

- [NetApp Config Advisor](https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor) (support login required) — automated config/cabling validation, useful pre- and post-change.
