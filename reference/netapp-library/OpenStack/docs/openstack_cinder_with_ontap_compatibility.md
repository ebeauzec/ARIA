# Openstack cinder with ONTAP compatibility
Source: https://kb.netapp.com/on-prem/ontap/Ontap_OS/OS-KBs/Openstack_cinder_with_ONTAP_compatibility
Fetched: 2026-07-07

## Applies to

- OpenStack Cinder
- ONTAP 9
- ONTAP 8

## Answer

The driver requires a storage controller running ONTAP 8.1.1 or later.
