- **Risk/design note**: NetApp Disaster Recovery and NetApp Backup and Recovery are complementary, not interchangeable — a DR plan gets you back online fast after a site loss (RTO-focused, via SnapMirror-replicated, bootable copies), while cloud backup gets you a long-tail, space-efficient recovery point (RPO/retention-focused). Don't rely on one where a design actually calls for the other. Cloud Tiering, by contrast, is a cost/capacity optimization, not a protection mechanism — tiered-cold data still depends on the same aggregate's redundancy/protection posture as hot data; confirm this distinction explicitly when a customer conflates "tiered to the cloud" with "protected in the cloud."
