# NetApp Cloud Tiering documentation
Source: https://docs.netapp.com/us-en/bluexp-tiering/
Fetched: 2026-07-07

Note: This URL now redirects to https://docs.netapp.com/us-en/data-services-cloud-tiering/ (BlueXP Cloud Tiering rebranded as "NetApp Cloud Tiering" under NetApp Data Services).

NetApp Cloud Tiering extends your data center to the cloud by automatically tiering inactive data from on-premises ONTAP clusters to object storage.
