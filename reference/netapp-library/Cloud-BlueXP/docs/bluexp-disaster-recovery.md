# NetApp Disaster Recovery documentation
Source: https://docs.netapp.com/us-en/bluexp-disaster-recovery/
Fetched: 2026-07-07

Note: This URL now redirects to https://docs.netapp.com/us-en/data-services-disaster-recovery/ (BlueXP Disaster Recovery rebranded as "NetApp Disaster Recovery" under NetApp Data Services).

Disaster recovery to the cloud is a resilient and cost-effective way of protecting workloads against site outages and data corruption events (for example, ransomware). With NetApp Disaster Recovery, you can replicate your on-premises VMware workloads running ONTAP storage to a VMware software-defined data center in a public cloud or to another on-premises site as a disaster recovery site.
