# NetApp Backup and Recovery documentation
Source: https://docs.netapp.com/us-en/bluexp-backup-recovery/
Fetched: 2026-07-07

Note: This URL now redirects to https://docs.netapp.com/us-en/data-services-backup-recovery/ (BlueXP Backup and Recovery rebranded as "NetApp Backup and Recovery" under NetApp Data Services).

NetApp Backup and Recovery is a data service that provides efficient, secure, and cost-effective data protection for all your ONTAP workloads, including volumes, databases, virtual machines, and Kubernetes workloads.
