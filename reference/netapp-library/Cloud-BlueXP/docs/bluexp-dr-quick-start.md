Overview of the steps needed to get started with NetApp Disaster Recovery.

## 1. Review prerequisites

[Ensure your system meets these requirements](https://docs.netapp.com/us-en/data-services-disaster-recovery/get-started/dr-prerequisites.html).

## 2. Set up NetApp Disaster Recovery

- [Set up the infrastructure for the service](https://docs.netapp.com/us-en/data-services-disaster-recovery/get-started/dr-setup.html)
- [Set up licensing](https://docs.netapp.com/us-en/data-services-disaster-recovery/get-started/dr-licensing.html)

## 3. What's next?

After you set up the service:

- [Add your vCenter sites to NetApp Disaster Recovery](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/sites-add.html)
- [Create your first resource group](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/manage.html#manage-resource-groups)
- [Create your first replication plan](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/drplan-create.html)
- [Replicate applications to another site](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/replicate.html)
- [Fail over applications to a remote site](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/failover.html)
- [Fail back applications to the original source site](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/failback.html)
- [Manage sites, resource groups, and replication plans](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/manage.html)
- [Monitor disaster recovery operations](https://docs.netapp.com/us-en/data-services-disaster-recovery/use/monitor-jobs.html)
