# NetApp Console documentation
Source: https://docs.netapp.com/us-en/bluexp-family/
Fetched: 2026-07-07

Note: This URL now redirects to https://docs.netapp.com/us-en/console-family/index.html (BlueXP has been rebranded as "NetApp Console").

The NetApp Console provides centralized management of storage and data services across on-premises and cloud environments. It delivers unified control, operational simplicity, and secured management. Browse documentation by feature or use search to find content.

## Documentation areas

- **NetApp Console administration** — Learn how to start using the NetApp Console, including setting up access management and Console agents. https://docs.netapp.com/us-en/console-setup-admin/index.html
- **NetApp Data Services** — Protect and secure your storage infrastructure. https://docs.netapp.com/us-en/data-services-family/index.html
- **Storage management** — Centralized management for both on-premises and cloud storage. https://docs.netapp.com/us-en/storage-management-family/index.html
- **Release notes** — Learn what's new across all of the NetApp Console platform and data services. https://docs.netapp.com/us-en/console-relnotes/index.html
- **API** — Programmatically administer your cloud-based resources. https://docs.netapp.com/us-en/console-automation/index.html
- **Automation hub** — Use scripted solutions to automate the deployment and integration of NetApp products and services. https://docs.netapp.com/us-en/netapp-automation/solutions/bac-overview.html
- **Data Infrastructure Insights** — Monitor, troubleshoot and optimize all your resources including your public clouds and your private data centers. https://docs.netapp.com/us-en/data-infrastructure-insights/task_cloud_insights_onboarding_1.html
- **Digital advisor (Active IQ)** — Actionable intelligence for optimal storage health. https://docs.netapp.com/us-en/active-iq/index.html
- **Licenses and subscriptions** — Manage and monitor your licenses and subscriptions. https://docs.netapp.com/us-en/console-licenses-subscriptions/index.html
- **Lifecycle planning** — Receive recommendations for systems nearing capacity limits and systems approaching the end of their service life. https://docs.netapp.com/us-en/console-lifecycle-planning/index.html
- **Software updates** — Automate the assessment, planning, and execution of ONTAP upgrades. https://docs.netapp.com/us-en/console-software-updates/index.html
- **Storage system alerts** — View and act on real-time system alerts for ONTAP on-premises systems. https://docs.netapp.com/us-en/console-alerts/index.html
- **Sustainability** — Monitor systems' environmental impact to achieve sustainability goals. https://docs.netapp.com/us-en/active-iq/learn_BlueXP_sustainability.html
