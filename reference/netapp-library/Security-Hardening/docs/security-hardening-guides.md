# ONTAP security hardening guides
Source: https://docs.netapp.com/us-en/ontap-technical-reports/security-hardening-guides.html
Fetched: 2026-07-07

These technical reports provide guidance on how to harden NetApp ONTAP as well as other NetApp products.

Note: These technical reports expand on the ONTAP security and data encryption product documentation (https://docs.netapp.com/us-en/ontap/security-encryption/index.html).

## Hardening guides

- **TR-4569: Security hardening guide for NetApp ONTAP** — https://docs.netapp.com/us-en/ontap-technical-reports/ontap-security-hardening/security-hardening-overview.html
  Learn how to configure NetApp ONTAP to help organizations meet prescribed security objectives for information system confidentiality, integrity, and availability.

- **Security hardening guide for ONTAP tools for VMware vSphere** — https://docs.netapp.com/us-en/ontap-apps-dbs/vmware/vmware-otv-hardening-overview.html
  Learn how to configure ONTAP tools for VMware vSphere to help organizations meet prescribed security objectives.

- **TR-4957: Security hardening guide for NetApp SnapCenter** — https://www.netapp.com/pdf.html?item=/media/82393-tr-4957.pdf
  Learn how to configure NetApp SnapCenter software to help organizations meet prescribed security objectives.

- **TR-4963: Security hardening guide: NetApp Backup and Recovery for Applications** — https://www.netapp.com/pdf.html?item=/media/83591-tr-4963.pdf
  Learn how to configure NetApp Cloud Backup for Applications to help organizations meet prescribed security objectives.

- **TR-4943: Security hardening guide for NetApp Active IQ Unified Manager** — https://netapp.com/pdf.html?item=/media/78654-tr-4943.pdf
  Learn how to configure NetApp Active IQ Unified Manager to help organizations meet prescribed security objectives.

- **TR-4945: Security hardening guide for NetApp Manageability SDK** — https://www.netapp.com/pdf.html?item=/media/78941-tr-4945.pdf
  Learn how to configure NetApp Manageability SDK (NMSDK) to help organizations meet prescribed security objectives.

- **Security hardening guide for MetroCluster Tiebreaker host and database** — https://docs.netapp.com/us-en/ontap-metrocluster/tiebreaker/install_security.html
  Learn how to configure the NetApp MetroCluster Tiebreaker host and database to help organizations meet prescribed security objectives.
