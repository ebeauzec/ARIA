# XCP documentation
Source: https://docs.netapp.com/us-en/xcp/
Fetched: 2026-07-07

NetApp XCP is a client-based software tool that allows for scalable and high-performance data migrations for any-to-NetApp and NetApp-to-NetApp data migrations and file analytics. NetApp provides documentation for the latest version of the XCP tool, as well as the three most recent versions.
